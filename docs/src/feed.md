# Feeds of a view

A build with the `feed` feature (`cargo build -p antares-broker --features feed`)
serves the feed outputs a view lists as Atom (RFC 4287), RSS 2.0 and JSON Feed
1.1 (T-5202; the contract is platform API/02 §8b, EP-150 and EP-151).

```text
GET /x/views/{view}/feed/v1/{name}/atom.xml
GET /x/views/{view}/feed/v1/{name}/rss.xml?limit=20&offset=20
GET /x/views/{view}/feed/v1/{name}/feed.json?lang=en&q=name=="Koncert"
```

Mount it with `ANTARES_API_SURFACES=admin,views,feed`. A feed is off by
default: a view serves one only for an output its `representations.feed` lists.
The gateway writes that list from the Endpoint's `spec.representations.feed`:

```json
{"representations": {"feed": [
  {"name": "sport", "version": 1, "title": {"sk": "Šport"}, "lang": "sk", "limit": 50,
   "sources": [{"type": "Event", "preset": "event", "mapping": {"updated": "dateModified"}}],
   "filter": {"q": "category==\"šport\""}}
]}}
```

- `sources` lists one or more types, each with a `preset` (`event`, `article`,
  `generic`) and/or a role `mapping`; the roles are `title`, `summary`,
  `content`, `link`, `updated`, `published`, `author`, `category` and `image`,
  each an attribute path or a list of them (the first with a value wins).
  `title` and `updated` are required.
- `filter` (`q`, `scopeQ`, `georel`, `geometry`, `coordinates`, `geoproperty`)
  narrows the view. A request's `q` and `scopeQ` are joined after it with `;`,
  and a request text whose parentheses or quotes do not balance is `400`, so a
  request never widens the filter. An output with a geometry refuses a request
  geometry.
- At most 20 outputs, names unique. A list that breaks this, or an output that
  does not compile, answers `500` with a fixed sentence (the gateway refuses it
  when the Endpoint is saved); a sibling that compiles still serves.

Each request is one NGSI-LD Query Entities of the output's types through the
view, so the view's rules, the Policy and the Tenant decide as for an NGSI-LD
client. Entries are sorted newest first by `updated`, then by id, and paged by
`limit` (default the output's, at most 200) and `offset`, with RFC 5005 `first`,
`previous` and `next` links (JSON Feed `next_url`). The other parameters are
`lang` and `attrs`, and `type` to keep some of the output's types. Any other
parameter, or one given twice, is `400`.

- An entry's id is `tag:{host},2026:{view}/{entity id}` (RFC 4151), the same in
  the three formats; `{host}` is the host of `ANTARES_PUBLIC_URL` (else of the
  request).
- Text is never markup: Atom and JSON Feed carry text alone, the RSS `title` and
  `description` are HTML-escaped once more, control characters are dropped, and
  a `link` or `image` that is not http(s) is left out.
- An Entity without a title or an `updated` time is left out and counted in
  `antares_surface_records_skipped_total{surface="feed",reason}` and the
  `antares-skipped-records` header.
- Every answer carries `ETag`, `Last-Modified` (the newest entry's `updated`)
  and `Cache-Control: max-age=300`; `If-None-Match`, else `If-Modified-Since`,
  answers `304`.

An unknown view, one that does not allow `query_entities`, one without the
output and an output whose types the view does not show answer the same `404`.
A read the Policy refuses answers the NGSI-LD refusal (`403`). `HEAD` answers
like `GET` without the body; every other method but `OPTIONS` is `405` with
`Allow`. The surface reads at most `RESIDUAL_SCAN` Entities per request and
answers `413` past it.

The conformance pack is [`tests/feed/README.md`](https://github.com/marek-mraz-jc/Antares-NGSI-LD-Context-Broker/blob/dev/tests/feed/README.md);
the crate was generated by `dev/new-surface.py` ([New surface](new-surface.md)).
